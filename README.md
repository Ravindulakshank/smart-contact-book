# Smart Contact Book 📖
A simple Python command-line application that acts as a digital address book, allowing users to save and search for phone numbers.

## Concepts Learned
- **Dictionaries (`{}`)**: Used to store data in **Key-Value** pairs (e.g., Name: Phone Number).
- **Dictionary Lookups**: Used the `in` keyword to efficiently search if a contact exists before accessing their number.
- **While Loops**: Kept the application running continuously until the user chooses to exit.
- **Conditional Logic**: Handled multiple user choices (`1. Add`, `2. Search`, `3. Exit`) using `if`, `elif`, and `else`.

## How to Run
1. Make sure you have **Python** installed.
2. Open your terminal in the project folder.
3. Run the application using:
   ```bash
   python contacts.py
